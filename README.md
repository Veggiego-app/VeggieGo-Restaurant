# VeggieGo Restaurant App

Restaurant Android application for VeggieGo Pure Veg Food Delivery.

## Features

- Restaurant Login
- Accept / Reject Orders
- Order Management
- Live Order Updates
- Menu Management
- Category & Subcategory Management
- Item Stock In / Out
- Item Show / Hide
- Restaurant Timing
- Analytics Dashboard

## Technology

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
